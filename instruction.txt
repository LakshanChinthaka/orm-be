Database migration

- add new entity to `entities` array in src/core/db/mikro-orm.config.ts
- pnpm build
- npx mikro-orm migration:create --dump
- pnpm db:migration:create
- check generated file in src/migrations/ before applying
- pnpm db:migration:up

Generate module

-  npx nest g module modules/product --no-spec

-  npx nest g service modules/product --no-spec
